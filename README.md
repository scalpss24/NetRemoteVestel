# Vestel Remote (Android, Kotlin + Jetpack Compose)

Виртуальный пульт дистанционного управления для телевизоров **Vestel** (шасси **MB130**, прошивка `3.62.7.3` и совместимых моделей) по локальной сети Wi-Fi.

## Возможности приложения
1. **Отправка команд в реальном времени:**
   - Эндпоинт: `POST http://<TV_IP>:56789/apps/SmartCenter`
   - Заголовок: `Content-Type: text/xml`
   - Тело запроса:
     ```xml
     <?xml version="1.0" ?><remote><key code="XXXX"/></remote>
     ```
   - Обработка ответов `HTTP 201 Created` / `HTTP 200 OK`.

2. **Полный набор клавиш управления:**
   - **Питание / Звук:** Power (`1012`), Mute (`1013`), Громкость +/- (`1016` / `1017`).
   - **D-Pad навигация:** Вверх (`1020`), Вниз (`1019`), Влево (`1021`), Вправо (`1022`), OK (`1053`), Back (`1010`).
   - **Каналы:** CH+ (`1032`), CH- (`1033`).
   - **Системные кнопки:** Home/Smart (`1046`), Menu (`1048`), Info (`1015`), Exit (`1037`), Source (`1056`).
   - **Цифровая клавиатура (0–9):** Коды `1000 + цифра` (раскрывается по кнопке с иконкой клавиатуры).
   - **Цветные кнопки:** Красная (`1055`), Зеленая (`1054`), Желтая (`1050`), Синяя (`1051`).
   - **Медиаплеер:** Play (`1025`), Pause (`1049`), Stop (`1024`), Rewind (`1027`), FastForward (`1028`).
   - **Произвольный ввод кодов:** Диалог с иконкой консоли для ввода и тестирования любого числового кода.

3. **Сетевые возможности и автообнаружение:**
   - По умолчанию настроен на IP `192.168.1.2`.
   - Автоматический опрос устройства через `GET http://<TV_IP>:56790/dd.xml` с получением `<friendlyName>` и `<tv_version>`.
   - SSDP-сканирование локальной сети (`239.255.255.250:1900`, DIAL service).
   - Быстрый параллельный опрос подсети на порты 56789 / 56790.
   - Возможность ручного ввода и сохранения любого IP.

4. **UI / UX:**
   - Стилизованный темный эргономичный интерфейс пульта на Jetpack Compose (Material 3).
   - Тактильный виброотклик (Haptic Feedback) на каждое нажатие.
   - Строка статуса с результатом выполнения каждой команды в реальном времени.

## Сборка и запуск
1. Откройте папку проекта `vestel-remote` в **Android Studio** (File -> Open).
2. Дождитесь синхронизации Gradle (Gradle Sync).
3. Подключите Android-устройство (или запустите эмулятор, подключенный к той же домашней Wi-Fi сети).
4. Нажмите **Run** (`Shift + F10`).
